# CloudMask

Клиент для безопасного подключения. Windows и Android.

Сайт и личный кабинет: **[cloudmaskvnp.site](https://cloudmaskvnp.site)**
Поддержка: **[@CloudMask_bot](https://t.me/CloudMask_bot)**

---

## Скачать

Все версии — на вкладке **[Releases](../../releases)**.

| Куда ставим | Файл |
|---|---|
| Windows 10/11 (64-бит) | `CloudMask-Setup-2.3.0.exe` |
| Android, обычный телефон | `CloudMask-2.3.0-android-arm64.apk` |
| Android, старый телефон | `CloudMask-2.3.0-android-arm32.apk` |

## Установка

### Windows

1. Скачайте `CloudMask-Setup-2.3.0.exe` и запустите.
2. Windows спросит разрешение — нажмите «Да». Права администратора нужны,
   чтобы программа могла создавать сетевое подключение.
3. После установки войдите в аккаунт: логин с паролем, Google или Telegram.

Если Windows покажет «Не удалось проверить издателя» — нажмите
«Подробнее» → «Выполнить в любом случае». Так бывает у программ без платной
подписи разработчика.

### Android

1. Скачайте `CloudMask-2.3.0-android-arm64.apk`.
2. Телефон предупредит об установке из неизвестного источника — разрешите
   установку для браузера.
3. Откройте приложение и войдите в аккаунт.

Не уверены, какой файл нужен — берите `arm64`. Он подходит почти всем
телефонам, выпущенным после 2016 года.

## Возможности

- Вход по логину и паролю, через Google или через Telegram
- Свои подписки и сторонние ссылки в одном списке
- Автоподключение к самому быстрому серверу
- Честная проверка серверов: проверяется реальное соединение, а не просто
  открытый порт
- Windows: выбор способа подключения — системный прокси, локальный SOCKS
  или полный туннель
- Windows: правила по программам — какие идут через подключение, какие мимо
- Android: выбор приложений, которым разрешено подключение
- Работа в фоне со значком в области уведомлений

---

## Требования

**Windows:** 10 или 11, 64-бит, права администратора.
**Android:** 5.0 и новее.

## Вопросы

- **Забыл пароль** — восстановление на [cloudmaskvnp.site](https://cloudmaskvnp.site)
- **Не подключается** — нажмите значок спидометра, приложение проверит серверы
  и подберёт рабочий
- **Всё остальное** — [@CloudMask_bot](https://t.me/CloudMask_bot)
